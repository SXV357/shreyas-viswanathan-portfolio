# [Shreyas Viswanathan](https://sxv357.github.io/shreyas-viswanathan-portfolio/) — Portfolio

Personal portfolio site for Shreyas Viswanathan — Purdue CS student interested in backend engineering (distributed systems + cloud infrastructure), full-stack engineering, and Computer Vision/Autonomous Systems. Built with **React** and **Bootstrap 5**.

## Getting Started

1. Clone the repo:
```
git clone https://github.com/SXV357/shreyas-viswanathan-portfolio.git
```

2. Go to the project's root folder and use npm to install all required components:
```
npm install
```

3. Launch the project in developer mode:
```
npm run dev
```

## About

This portfolio is based on the **[React Portfolio Template](https://ryanbalieiro.github.io/react-portfolio-template/)**, originally created by **[Ryan Balieiro](https://ryanbalieiro.com/)**. Customized and maintained by **[Shreyas Viswanathan](https://www.linkedin.com/in/shrevis)**.

It's based on the **[React](https://reactjs.org/)** framework created by Jordan Walke, and the **[Bootstrap](https://getbootstrap.com/)** framework created by Mark Otto and Jacob Thorton.

Additional frameworks and plugins used include:
- **Smooth Scrollbar**: A customizable scrollbar plugin.
- **Swiper**: A powerful library for creating touch sliders.
- **EmailJS**: A free service that allows you to send emails using JavaScript.
- **Font Awesome**: A library of free vector icons.
- **PrimeIcons**: A collection of premium line icons.
